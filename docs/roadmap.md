# Delivery roadmap

1. Foundation: contracts, repository, configuration, Compose, and tests.
2. Core: migrations, authentication, audit, inventory, Go agent enrollment and heartbeat, metrics, dashboard, retention, and scoped tokens.
3. Availability: checks, outage state, incidents, correlation, Resend, deduplication, and maintenance windows.
4. Discovery: subnet policies, safe Nmap adapter, identity reconciliation, port changes, and scheduler controls.
5. Vulnerabilities: Trivy, OSV, CISA KEV, advisory normalization, evidence, workflow, and rescans.
6. Storage and Docker: metadata analysis, growth detection, inventory, protected items, and conservative recommendations.
7. Behavior: per-device baselines, explainable anomaly rules, resource pressure, and confidence scoring.
8. Release: performance, security review, installers, backup/restore, upgrades, Portainer verification, SBOMs, and UI polish.

Every phase ends deployable, tested, migrated, and threat-model reviewed.
